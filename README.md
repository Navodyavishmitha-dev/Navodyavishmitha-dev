## 👋 About

I'm **Navodya Vishmitha**, a Physical Sciences student from Colombo, Sri Lanka.
I'm learning artificial intelligence, physics and robotics through free
university coursework (Harvard, MIT, Stanford) and documenting everything I
build along the way.

I'm an absolute beginner in AI, and I'm not hiding it. This profile is a public
record of the journey: what I study, what I build, what breaks, and what I fix.

At school I served as **Deputy Head Prefect**, **Media President** and
**Science & Maths Society President**, which taught me leadership,
communication and teamwork alongside the science.

## 🚀 Vision

> Become a technology entrepreneur and scientist in Sri Lanka, and eventually
> establish a Sri Lankan space technology company.

Space technology sits at the meeting point of physics, AI, robotics and
engineering. Every course and project here is a step in that direction.

### 2. FLOODLENS: Flood Information Intelligence Platform
**Status:** In progress (MVP)  |  **Stack:** Python, FastAPI

A platform that brings flood-related information together in one place, built
as an MVP first and improved step by step. Floods affect many communities in
Sri Lanka, so I want this to be useful in the real world.

- Backend API built with FastAPI
- Focus on clear, reliable information
- Repository link will be added once it is pushed to GitHub

### 3. LOST VALLEY: 3D Adventure Game
**Status:** In progress  |  **Stack:** Godot, GDScript

A small 3D adventure game set in a Sri Lankan jungle with ancient ruins. It is
my way of learning game development, 3D worlds and programming logic through
something fun.

- Built in the Godot engine with GDScript
- Sri Lankan jungle and ruins as the setting
- Repository link will be added once it is pushed to GitHub

### 4. Brain-Computer Interface (long-term)
**Status:** Planning, built step by step

A long-term project exploring brain-computer interfaces. It connects AI,
physics and robotics, so it is a good target for everything I'm learning.
